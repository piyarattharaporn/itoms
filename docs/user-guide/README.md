## หลักการอ่านตัวเลขในระบบ

ระบบนี้เป็นเครื่องมือสำหรับติดตามและรายงานแบบ bounded/manual บน Firebase Spark ตัวเลขบนหน้าจอจึงหมายถึงข้อมูลที่ระบบโหลดมาแล้วในขอบเขต Property และช่วงเวลาที่เลือก ไม่ควรตีความเป็นยอดรวมประวัติทั้งหมดโดยอัตโนมัติ

ก่อนสรุปผลหรือส่งรายงาน ให้ตรวจสอบเสมอว่า:

1. เลือก Property ถูกต้อง
2. เลือกช่วงเวลาถูกต้อง
3. โหลดข้อมูลเพิ่มจนถึงขอบเขตที่ต้องการแล้ว
4. ใช้ปุ่ม Export ของมุมมองปัจจุบันเมื่อจำเป็นต้องเก็บหลักฐานการรายงาน

เอกสารนี้เป็นคู่มือการใช้งาน ไม่ใช่เอกสารอนุมัติ SLA ตามสัญญาหรือเอกสารกำหนดสิทธิ์ทางกฎหมาย
